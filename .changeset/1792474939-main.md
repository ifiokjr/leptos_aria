# Combo box filters as you type and commits on enter

An uncontrolled combo box now filters its options as you type: the input text has a single source of truth, controlled or uncontrolled. The arrow keys move focus through the visible options and enter (or a click) selects the focused option and moves its label into the input. `ListBox` gains an optional `focused_key` prop so an owner such as the combo box input can drive option focus. `ComboBox` also gains a `class` prop, added after the built-in `leptos-aria-combo-box` class on a new root element.
