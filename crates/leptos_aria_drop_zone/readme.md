# leptos_aria_drop_zone

> Accessible drop zone and draggable items for Leptos.

Part of [`leptos_aria`](https://crates.io/crates/leptos_aria), headless and accessible Leptos components ported from React Aria. Most projects depend on the `leptos_aria` facade crate, which re-exports this one.
