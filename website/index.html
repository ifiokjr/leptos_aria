leptos_aria

Headless accessible components for Leptos, ported from React Aria with the Radix/shadcn primitive surface completed. No styles ship; state is exposed as data-* attributes for Tailwind v4.

Quick start

cargo add leptos_aria
cargo install leptos_aria_cli
leptos-aria add button

Tailwind v4

Style states with the data-[state=open] arbitrary variants, or name them once with @custom-variant. See the Tailwind guide and the registry.json.
