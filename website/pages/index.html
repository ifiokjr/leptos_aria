React Aria, ported to Leptos

Accessible by default.
Styled by you.

leptos_aria brings React Aria's keyboard, focus, and screen-reader behaviour to Leptos and ships zero CSS. Every state is a data-* attribute, so Tailwind v4 styles it with the classes you already write.

$ cargo add leptos_aria

Read the guide View on GitHub

01

Three moves, no stylesheet to fight

  1. Add the crate

    One facade crate re-exports every component, hook, and utility.

    $ cargo add leptos_aria

  2. Compose the parts

    Components handle roles, keyboard, and focus. You write markup and classes.

    view! {
  <AccordionItem key="faq".to_string()>
    <AccordionTrigger
      class="data-[state=open]:font-bold">
      "Is it accessible?"
    </AccordionTrigger>
    <AccordionPanel>"By default."</AccordionPanel>
  </AccordionItem>
}

  3. Style the state

    Name the states once and every component speaks the same variants.

    @custom-variant open
  (&:where([data-state="open"]));

<button class="open:bg-orange-500">

02

The hard parts, already written

  • Press, hover, and focus that agree

    Mouse, touch, pen, keyboard, and screen-reader virtual clicks all arrive as one normalised press event.

  • Focus goes where it should

    Containment inside modals, restoration on close, autofocus, and a programmatic FocusManager.

  • Overlays that close properly

    Escape and outside-press dismissal, scroll locking, and popovers that flip and shift to stay on screen.

  • Collections you can drive by keyboard

    Arrow keys, Home and End, and type-ahead across list boxes, menus, grids, tables, and trees.

  • Calendar and colour maths

    Date arithmetic, ranges, and time fields, plus colour areas, sliders, and wheels that read correctly aloud.

  • Copy, don't install

    A shadcn-style CLI drops styled wrappers into your crate. The files are yours to edit.

04

Own the styled layer

Like shadcn/ui: the CLI copies Tailwind-styled components into src/components/ui, wires up the modules and theme, and the files become yours. The headless crates stay underneath. Browse the components or read the CLI guide. 

# once
$ cargo install leptos_aria_cli
$ leptos-aria init

# per component, and again after upgrades
$ leptos-aria add button dialog switch
$ leptos-aria diff
